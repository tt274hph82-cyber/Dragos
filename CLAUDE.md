# Channel rules

- Every long video is at least 8 minutes.
- Same style for every video: the warm desk world, orange accent #FF5A1F, Archivo Black + Inter, Maya as the recurring example creator. Copy `videos/thumbnails-that-click/` (build.mjs, src/shared.*, script/make_voice.py) as the starting point.
- Exception: `videos/shorts-vs-long/` is in a Liquid Glass style (frosted glass panels over moving colour light) at the user's request. Use it as the starting point when Liquid Glass is asked for.
- Same voice: Kokoro `af_heart` at speed 0.92 (`script/make_voice.py`).
- Each video ships with a 1280×720 thumbnail, a description with chapter timestamps, and comma-separated tags, in its `youtube/` folder.
- On-screen numbers that aren't real data are labelled "illustrative".
